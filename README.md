# Simple Interest Calculator

A simple script/application that calculates simple interest based on the principal amount, annual interest rate, and time period in years.

## Simple Interest Formula

The formula used to calculate simple interest is:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (in %)
- **T** = Time period (in years)

## Total Amount Formula

$$\text{Total Amount} = P + \text{Simple Interest}$$

## Features
- Calculates Simple Interest easily
- Provides total pay-back amount
- Fast and accurate
